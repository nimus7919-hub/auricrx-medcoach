Current correction reviewed 2026-11-03:

- Cilantro now uses the Commons photo [Coriandrum sativum 003.JPG](https://commons.wikimedia.org/wiki/File:Coriandrum_sativum_003.JPG), H. Zell, crop by Epipelagic, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). It shows flowering cilantro, not soil. The file history identifies the existing Commons crop; no additional crop is made by the app. Direct image: https://upload.wikimedia.org/wikipedia/commons/7/7c/Coriandrum_sativum_003.JPG . Because local network downloads are unavailable in this workspace, it is loaded by URI with a local neutral fallback on loading failure. All original local files are retained.
- Yerba Mansa: the old PNG appears to show Houttuynia-like foliage and a four-bracted flower, not diagnostic Anemopsis californica. It now uses the neutral herb icon pending a licensed, verified replacement.
- Aristolochia: the genus-level illustration does not establish A. odoratissima. It now uses the neutral icon pending a species-specific replacement.
- The other 29 mapped images were reviewed in [herb-current-audit.jpg](herb-current-audit.jpg): the 16 previously credited Commons photos show the named plants or plant parts; the 13 retained local illustrations show recognizable plant material (agastache, aloe, dandelion, echinacea, fennel, ginger, ginkgo, lavender, milk thistle, parsley, prunella, rosemary, turmeric). The previous cilantro illustration was also reviewed and has now been replaced. Existing illustrations have no Commons attribution and are not presented as Commons photographs. These are visual checks, not specimen authentication.
- Ten entries currently use the neutral icon: epazote, tagetes_lucida, clinopodium_mexicanum, notoginseng, aristolochia, yerba_mansa, gray_sarsaparilla, pericon, liquorice and angelica_sinensis. No licensed and visually verified local replacement is available for these entries. Their old files remain on disk.
- Card thumbnails use a 170 px image box; details use 260 px, both with contain sizing. Author, license and Commons links remain visible in photo details. Neutral fallbacks are never plant-identification photos.
